# Project: Todo API

## Objective

* Create a todo application using flask, redis and docker compose

## Commands Practiced

* docker compose up - Start containers
	- -d - detached mode
* docker compose up --build - Build images first, then start containers
* docker compose down - Stop and remove containters


## What I did

* Created python app, requirements file, Dockerfile, yml file
* Ran the containers and tested from the browser
* Created and deleted tasks
* Checked list of tasks from terminal and browser
